Mastering Git and GitHub

A structured, hands-on learning journey covering Git fundamentals, commit best practices, branching, remote workflows, Pull Requests, and automation.

Labs

  • Lab 01 — Introduction to Git and GitHub

    Installation, initialization, branching, and first push.

  • Lab 02 — The Ultimate Guide to Writing a Good Commit Message

    Commit anatomy, conventional commits, linting, and history hygiene.

  • Lab 03 — Free Hosting For Web Projects

    Compare free hosting platforms and deployment workflows.

  • Lab 04 — Mastering Git Workflows and Merge Conflict Resolution

    Branching models, merging, rebasing, and conflict resolution.

  • Lab 05 — Everyday Git: Inspecting Changes and Working with Remotes

    Status, diffs, history, remotes, fetch, pull, and upstream branches.

  • Lab 06 — Undoing Changes and Recovering Work

    Restore, revert, reset, stash, and reflog with safe-use guidance.

  • Lab 07 — GitHub Collaboration: Issues, Pull Requests, and Reviews

    Track work, review changes, protect branches, and choose merge strategies.

  • Lab 08 — Automating Workflows with GitHub Actions

    Workflow triggers, jobs, CI checks, secrets, permissions, and deployments.

  • Lab 09 — Git Tags, Versioning, and GitHub Releases

    Mark versions, use semantic versioning, and publish releases.

  • Lab 10 — Advanced Git Tools and Repository Management

    Cherry-pick, bisect, blame, worktrees, submodules, and Git LFS.

  • 30-Day Git Challenge

    Practice exercises and challenges.
