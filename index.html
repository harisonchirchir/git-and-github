A hands-on course

Mastering Git and GitHub

Build practical version-control skills one lesson at a time, from your first local commit to reviewed, automated releases.

Start here: Lab 01

No prior Git experience required. You will need Git installed, a terminal, and a GitHub account for the collaboration lessons. Each lesson includes an estimated time and a hands-on checkpoint.

Your learning path

  1. Start with the foundations: Labs 01–02 cover Git setup, repositories, commits, and commit messages.
  2. Practice everyday work: Labs 04–06 teach workflows, remotes, and safe recovery.
  3. Collaborate and ship: Labs 07–09 cover pull requests, Actions, and releases.
  4. Go deeper: Lab 10 introduces advanced tools. Finish with the 30-day challenge.

Where does hosting fit? Lab 03 is an optional deployment lesson. Take it after Lab 01 if you want to publish a project early, or after Lab 08 to connect hosting concepts with automated deployment.
